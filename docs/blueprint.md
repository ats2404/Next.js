# **App Name**: ATS calculator

## Core Features:

- ATS Compatibility Check: Analyze resume content to identify elements that may cause issues with Applicant Tracking Systems.
- Keyword Extraction: Extract relevant keywords from the provided job description to optimize the resume content.
- ATS Error Identification: Utilize a generative AI tool to analyze the resume content and identify potential ATS parsing errors and areas for improvement.
- Formatting Recommendations: Offer automated recommendations to ensure that resume formatting is ATS-friendly.
- Downloadable ATS Report: Generates a downloadable report that contains ATS compatibility feedback and parsing improvements.

## Style Guidelines:

- Primary color: Sky blue (#74B9FF) to convey trustworthiness and competence.
- Background color: Very light blue (#F0F8FF), nearly white, to provide a clean and professional backdrop.
- Accent color: A slightly muted violet (#946BE3) for interactive elements.
- Headline font: 'Space Grotesk' sans-serif for a tech-forward, contemporary look. Body font: 'Inter' sans-serif for readability.
- Use simple, clear icons that relate to the ATS analysis and feedback. Favor filled icons for clarity.
- Maintain a clean and structured layout to present analysis and recommendations clearly. Use whitespace to separate content effectively.
- Incorporate subtle animations, like progress loaders and feedback display.
